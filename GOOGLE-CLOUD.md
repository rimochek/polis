# Gemini в Polis

Локальная рабочая версия: http://127.0.0.1:5173/ (`npm run dev`).
Публичный Vercel-лендинг пока содержит отдельное синтетическое демо.

## Подключение

1. Откройте «Настройки анализа» в локальном Polis.
2. Выберите API-ключ Vertex AI или временный OAuth access token Google Cloud.
3. Укажите ID Cloud-проекта с активным биллингом/кредитами и включённым API Vertex AI (в актуальной консоли — Agent Platform).
4. Сохраните доступ и выполните проверку. Приложение отправляет короткий технический запрос без документов.
5. Создайте заявку, добавьте 2–3 PDF и нажмите «Анализировать».

Если организация запрещает API-ключи, для презентации можно получить временный токен в Cloud Shell командой `gcloud auth print-access-token`. Он обычно истекает примерно через час; это временный способ, не автоматическое обновление авторизации. Для постоянной эксплуатации нужно настроить ADC/workload identity.

Секрет хранится в `.env` на сервере и не возвращается в `/api/config`, не попадает в сборку или Git. Настройки применяются без перезапуска. В `.env.example` перечислены переменные. `GOOGLE_VERTEX_EXPRESS=true` предусмотрен для Express Mode через конфигурационный файл; обычное подключение использует указанный проект.

## Что проверено

Сборка TypeScript/Vite и тесты нормализации, формирования запроса Gemini, отклонения незавершённых ответов и безопасного отображения ошибок. Mock-тесты не подтверждают доступ к реальному Google API; реальный результат сохраняется отдельно после успешной проверки доступа.

Для реального smoke-теста на вымышленных PDF: `node scripts/gemini-presentation-check.mjs --analyze`. Результат — `artifacts/gemini/live-analysis.json`. Учебный кейс явно подписан в приложении; его AI-анализ не использует заранее готовую таблицу демо.

Результаты Gemini проходят ту же проверку восьми полей, ссылок и номеров страниц. Подтверждение цитат по смыслу и итогового предложения остаётся за брокером. Ошибка API не подменяется демонстрационным результатом.

## Google Cloud кредиты

Google Cloud Free Trial не покрывает Gemini API в AI Studio. Интеграция использует домен `aiplatform.googleapis.com` и проект Google Cloud. Фактическое применение кредита, доступные модели и квоты зависят от аккаунта.

- https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start/api-keys
- https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/gemini/3-8-flash
